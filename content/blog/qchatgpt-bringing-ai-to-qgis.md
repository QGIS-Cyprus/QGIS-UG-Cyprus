# QChatGPT — Bringing AI to QGIS

**QChatGPT** is an open-source QGIS plugin that connects QGIS to ChatGPT, letting you ask questions, load data, and run Python — all from inside the QGIS console. It picked up 6,000 downloads in its first ten days.

{{< youtube Uo1gdf0eH7o >}}

## What's in v0.5

- AI voice response
- A microphone button for voice input, with a configurable recording duration
- An option to stop voice response mid-playback
- Saving the previous AI response for future reference
- Executing Python code and integrating with the QGIS Python console
- Support for data input via links, not just GeoJSON files
- Completing questions using QGIS and QCode context
- Editing the AI's response before use — for example, tweaking a GeoJSON reply before adding it to the map
- Whisper models for speech-to-text transcription
